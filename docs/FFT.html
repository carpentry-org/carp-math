fft

defn

(Fn [(Ref (Array Complex) a)] (Array Complex)) 

                        (fft arr)

performs a 1D FFT on the array of complex numbers. Asserts that the length is a power of two.

fft!

defn

(Fn [(Ref (Array Complex) a), Bool] ()) 

                        (fft! arr inverse)

performs a 1D Cooley-Tukey Radix-2 FFT in-place on the given array of complex numbers. Set inverse to true for IFFT. Asserts that the length of the array is a power of two.

                        (fft2d arr rows cols)

performs a 2D FFT on a flat array of size rows x cols. Asserts size and powers of two.

defn

(Fn [(Ref (Array Complex) a), Int, Int, Bool] ()) 

                        (fft2d! arr rows cols inverse)

performs a 2D Cooley-Tukey Radix-2 FFT in-place on the given flat array representing a 2D grid of size rows x cols.
