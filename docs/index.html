carp-math

A math suite for Carp: colour spaces, complex numbers, matrices, quaternions and transforms, noise, SIMD, and an FFT with the windowing and convolution that go with it.

Load the whole suite, or any single module on its own:

(load "git@github.com:carpentry-org/carp-math@master")
; or, for just one:
(load "git@github.com:carpentry-org/carp-math@master" "matrix.carp")

Colour

  • Color — conversion between RGB, RGBA, HSL, HSV and CMYK

Linear algebra

  • Mat — dense Matrix arithmetic
  • Quaternion — rotations
  • TransformMat4 — 4x4 matrices, column-major
  • Transform — translation, rotation and scale together

Signal

  • Complex — complex arithmetic
  • FFT — fast Fourier transform
  • Window — window functions
  • Spectrum — spectral analysis
  • Convolution — FFT-based convolution

Noise

  • Noise — perlin and simplex noise, with FBMConfig for fractal brownian motion

SIMD

  • Simd, SimdFloat, SimdInt — vectorized primitives
  • SimdArray — vectorized array operations

A note on the file name

The colour module lives in colors.carp, not color.carp. Carp searches the working directory before the directory of the file doing the loading, and carp's own Test.carp starts with (load "Color.carp"). On a case-insensitive filesystem a color.carp in the project root answers that load instead of core's, and every test in the project fails to find IO.colorize.
